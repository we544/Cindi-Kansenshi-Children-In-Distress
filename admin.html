Security

Account, session, and data controls.

Server-backed access Passwords are hashed on the server and admin APIs require a server-verified session cookie. Use HTTPS in production, set a stable CINDI_SECRET_KEY, restrict access to the server and its data directory, and keep regular backups. Do not store sensitive case, donor, or financial records in this public-content dashboard.

Uploaded media is stored in the server's data directory and served to site visitors. Back up the database and uploads directory together.
